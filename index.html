Теория коротко

Что происходит в линии

Длинная линия — цепь, где индуктивность и ёмкость распределены по длине. Если линия сравнима с длиной волны, фаза напряжения заметно меняется вдоль неё, и ток с напряжением становятся функциями координаты x. В линии без потерь (R₀ = 0, G₀ = 0) остаются только L₀ и C₀.

Напряжение и ток в любой точке — сумма двух бегущих волн: прямой (к нагрузке) и обратной (от нагрузки). Если отсчитывать x от нагрузки, то для действующих комплексов:

\[\underline U(x)=\underline U_2\cos\beta x+j Z_C\underline I_2\sin\beta x,\qquad \underline I(x)=\underline I_2\cos\beta x+j\frac{\underline U_2}{Z_C}\sin\beta x\]

Здесь β = ω√(L₀C₀) — коэффициент фазы, ZC = √(L₀/C₀) — волновое сопротивление. Входное сопротивление отрезка длиной x:

\[\underline Z_{вх}(x)=Z_C\,\frac{\underline Z_н+jZ_C\,\mathrm{tg}\,\beta x}{Z_C+j\underline Z_н\,\mathrm{tg}\,\beta x}\]

Почему цепочка звеньев заменяет кабель. Звено ФНЧ в полосе пропускания (f < f₂) имеет вещественное характеристическое сопротивление ZC и коэффициент фазы B, где cos B = 1 − ω²LC/2. Напряжения в узлах цепочки описываются теми же формулами, что и линия, только βx заменяется на nB:

\[\underline U(n)=\underline U(0)\cos nB+jZ_C\underline I(0)\sin nB\]

Одно звено соответствует отрезку кабеля l₁ = 1 км (L/L₀ = 0,24/0,24). При B = π/8 на длину волны приходится 16 звеньев, поэтому 10 звеньев — это 0,625 λ. Цепочка показывает только дискретные точки линии с шагом l₁, а её ZC растёт с частотой и уходит в бесконечность на f₂. Поэтому рабочую частоту берут низкой, чтобы шаг по фазе был мал.

Коэффициент стоячей волны kс = Umax/Umin. При чисто активной нагрузке kс = Rн/ZC (если Rн > ZC) или ZC/Rн (если Rн < ZC). Согласованный режим: kс = 1. ХХ, КЗ и реактивная нагрузка: kс = ∞.

Согласованная, Zн = ZC
\(U(x)=U_2,\;\psi=\beta x\)

Только прямая волна, режим бегущей волны. Действующее значение одинаково по всей длине, фаза растёт линейно.

Холостой ход, Zн = ∞
\(U=U_2|\cos\beta x|,\;I=\frac{U_2}{Z_C}|\sin\beta x|\)

Стоячая волна. У нагрузки пучность напряжения, на λ/4 — узел. В опыте узел на n = 4.

Короткое замыкание, Zн = 0
\(U=Z_CI_2|\sin\beta x|,\;I=I_2|\cos\beta x|\)

Стоячая волна, у нагрузки узел напряжения и пучность тока. Картина ХХ, сдвинутая на λ/4.

Реактивная, Zн = ±jX
\(U=U_2\frac{|\cos\beta(x+y)|}{|\cos\beta y|}\)

Стоячая волна со сдвигом: нагрузку заменяют отрезком разомкнутой линии длиной y. Ёмкость: узел ближе λ/4. Индуктивность: узел дальше λ/4.

Рабочее задание

Что делать на стенде и что должно получиться

1

Выбор рабочей частоты

Собрать цепочку с перемычкой K, подать Uвх ≈ 5–7 В на частоте около 12–13 кГц. Нагрузку отключить (ХХ) и подстроить частоту так, чтобы на 4-м узле от нагрузки напряжение было почти нулевым. Дальше частоту не трогать.

Ожидаемо: f ≈ 12,7 кГц (расчёт 12,68 кГц). Небольшая разница — разброс номиналов L и C на стенде.

2

Исследование одного звена

Снять перемычку K, измерить U1х и U2х одного звена на ХХ. В полосе пропускания они совпадают по фазе, и B находится из отношения:

\[\cos B=\frac{U_{2х}}{U_{1х}}\]

Затем включить Rн = ZC ≈ 50 Ом и проверить, что U₁ = U₂.

Ожидаемо: U2х/U1х = cos 22,5° = 0,924, например 6,0 В → 5,54 В. При ХХ U₁ и U₂ в фазе, при ZC — равны по модулю и сдвинуты на 22,5°.

3

Согласованный режим

Восстановить цепочку, нагрузить на резистор ≈ ZC, измерить U(n) во всех узлах. Двулучевым осциллографом измерить фазу φ(n) относительно нагрузки: 8 клеток на период, 45° на клетку.

Ожидаемо: U(n) ≈ const, φ(n) = 22,5°·n, то есть полклетки на звено. Годограф — окружность, векторы через 22,5°.

4

Режим стоячих волн

Измерить U(n) на ХХ, затем с конденсатором Cн ≈ 0,1 мкФ из модуля конденсаторов.

Ожидаемо: ХХ — узел на n = 4, пучности на n = 0 и 8. С ёмкостью картина сдвигается на одно звено: узел на n = 3, пучность на n = 7.

5

Активная нагрузка (по указанию преподавателя)

Магазином сопротивлений поставить Rн = 2ZC ≈ 100 Ом, затем 0,2ZC ≈ 10 Ом. Найти Umax, Umin, kс.

Ожидаемо: при 2ZC минимум на n = 4, kс = 2. При 0,2ZC минимум у нагрузки, максимум на n = 4, kс = 5. Узлы не нулевые: часть энергии уходит в нагрузку.

Ответы на все 14 вопросов

U(0) = U₂ — напряжение на нагрузке, B = 22,5°, ZC ≈ 50 Ом. Где в вопросе номер звена задаёт преподаватель, есть калькулятор.

1Показание вольтметра между нагрузкой и n-м звеном: а) согласованная нагрузка, б) ХХ

Вольтметр показывает модуль разности комплексов: |U(n) − U(0)|.

\[а)\;U_V=U_2\left|e^{jnB}-1\right|=2U_2\sin\frac{nB}{2}\qquad б)\;U_V=U_2\left(1-\cos nB\right)\]
а) б)
2Показание вольтметра между n-м и m-м звеньями: а) согласованная нагрузка, б) ХХ
\[а)\;U_V=2U_2\sin\frac{|n-m|B}{2}\qquad б)\;U_V=U_2\left|\cos nB-\cos mB\right|\]

На ХХ все напряжения узлов вещественны (в фазе или в противофазе), поэтому разность — просто разность косинусов со знаком.

а) б)
3Найти n и m, при которых на ХХ Zвх(n) = Zвх(m) и Zвх(n) = Z*вх(m)
\[\underline Z_{вх}(n)=-jZ_C\,\mathrm{ctg}\,nB\]

Равенство: ctg периодичен с периодом π, значит (m − n)B = π, m = n + 8. В цепочке это пары (0, 8), (1, 9), (2, 10).

Сопряжённые: ctg mB = −ctg nB, значит (n + m)B = π, n + m = 8: пары (1, 7), (2, 6), (3, 5). Например, Zвх(1) = −j120,6 Ом (ёмкостное), Zвх(7) = +j120,6 Ом (индуктивное). Также n + m = 16: (6, 10), (7, 9).

4Номер звена при ёмкостной нагрузке, где Zвх(n) = Zн и Zвх(n) = Z*н

Cн эквивалентна одному разомкнутому звену, поэтому

\[\underline Z_{вх}(n)=-jZ_C\,\mathrm{ctg}\,(n+1)B,\qquad \underline Z_н=-jZ_C\,\mathrm{ctg}\,B\]

Zвх(n) = Zн: nB = π, n = 8. Zвх(n) = Z*н (то же |Z|, но индуктивное): (n + 2)B = π, n = 6.

5Распределение модуля входного сопротивления |Zвх(n)|: согласованная, ХХ, ёмкостная
\[а)\;|Z_{вх}|=Z_C\qquad б)\;|Z_{вх}|=Z_C|\mathrm{ctg}\,nB|\qquad в)\;|Z_{вх}|=Z_C|\mathrm{ctg}\,(n+1)B|\]

ХХ: ∞ на n = 0 и 8, ноль на n = 4. Ёмкостная: ∞ на n = 7, ноль на n = 3. График — вкладка «|Zвх(n)|» на стенде.

6Распределение действующего тока I(n) при известном U₂: согласованная, ХХ, ёмкостная
\[а)\;I=\frac{U_2}{Z_C}\qquad б)\;I=\frac{U_2}{Z_C}|\sin nB|\qquad в)\;I=\frac{U_2}{Z_C}\frac{|\sin(n+1)B|}{\cos B}\]

Узлы тока там, где пучности напряжения, и наоборот. При U₂ = 1 В и ZC = 50 Ом согласованный ток 20 мА. Вкладка «I(n)» на стенде.

7Векторные диаграммы U(n) и I(n) для заданного звена n: согласованная, ХХ, ёмкостная

Относительно U(0) = U₂ (вектор по оси +1):

  • Согласованная: U(n) = U₂ejnB, I(n) = (U₂/ZC)ejnB — векторы совпадают по направлению, повёрнуты на nB.
  • ХХ: U(n) = U₂cos nB — на оси; I(n) = j(U₂/ZC)sin nB — опережает на 90° (или отстаёт, если sin < 0).
  • Ёмкостная: U(n) = U₂cos(n+1)B / cos B — на оси; I(n) = j(U₂/ZC)sin(n+1)B / cos B — перпендикулярно.
8Мгновенные значения un(t) и in(t): согласованная, ХХ, ёмкостная

Принимаем ψu2 = 0, действующее U₂:

\[а)\;u_n=\sqrt2U_2\sin(\omega t+nB),\quad i_n=\sqrt2\frac{U_2}{Z_C}\sin(\omega t+nB)\]
\[б)\;u_n=\sqrt2U_2\cos nB\,\sin\omega t,\quad i_n=\sqrt2\frac{U_2}{Z_C}\sin nB\,\sin(\omega t+90^\circ)\]
\[в)\;u_n=\sqrt2U_2\frac{\cos(n+1)B}{\cos B}\sin\omega t,\quad i_n=\sqrt2\frac{U_2}{Z_C}\frac{\sin(n+1)B}{\cos B}\sin(\omega t+90^\circ)\]
9Линия нагружена на чисто реактивную нагрузку. Как по графику U(x) определить её характер?

Реактивная нагрузка даёт стоячую волну с нулями напряжения. Смотрим, где ближайший к нагрузке узел:

  • узел ближе λ/4 (в цепочке n < 4) — нагрузка ёмкостная (эквивалент разомкнутого отрезка y < λ/4);
  • узел дальше λ/4, а ближе λ/4 стоит пучность — индуктивная (эквивалент короткозамкнутого отрезка);
  • узел ровно на λ/4 — ХХ; узел на самой нагрузке — КЗ.
10Распределение U(n) и I(n) в режиме КЗ при известном I₂
\[U(n)=Z_CI_2\,|\sin nB|,\qquad I(n)=I_2\,|\cos nB|\]

Узлы напряжения на n = 0 и 8, пучность на n = 4. Это ХХ, сдвинутый на λ/4. Выбери «Короткое замыкание» на стенде.

11U(n), если нагрузка равна входному сопротивлению одного короткозамкнутого звена
\[\underline Z_н=jZ_C\,\mathrm{tg}\,B=j20{,}7\;Ом\;(L_н=0{,}26\;мГн),\qquad \frac{U(n)}{U(0)}=\frac{|\sin(n+1)B|}{\sin B}\]

Индуктивная нагрузка заменяет одно звено с КЗ: картина КЗ сдвигается на одно звено. Узел на n = 7, пучность 2,61·U(0) на n = 3. На стенде: «Индуктивность Lн» → «как 1 звено при КЗ».

12Векторные диаграммы U(n), I(n) и годограф при Rн = 2ZC
\[\underline U(n)=U_2\left(\cos nB+j\tfrac12\sin nB\right),\qquad \underline I(n)=\frac{U_2}{2Z_C}\left(\cos nB+j\,2\sin nB\right)\]

Годограф U(n) — эллипс с полуосями U₂ (по оси) и 0,5U₂; концы векторов идут по эллипсу через каждые 22,5° «эллиптического угла». Годограф I(n) — эллипс с полуосями 0,5U₂/ZC и U₂/ZC.

13Векторные диаграммы U(n), I(n) и годограф при Rн = 0,2ZC
\[\underline U(n)=U_2\left(\cos nB+j\,5\sin nB\right),\qquad \underline I(n)=\frac{5U_2}{Z_C}\left(\cos nB+j\,0{,}2\sin nB\right)\]

Годограф U(n) — эллипс, вытянутый по мнимой оси: полуоси U₂ и 5U₂. На n = 4 вектор U(4) = j5U₂ — максимум. Распределение U(n) — на стенде: «Активная» → «R = 0,2ZC».

14B и ZC одного звена на частоте 5f. Возможно ли моделирование, каков шаг l′?

5f = 63,38 кГц, ω′ = 398 226 рад/с, ω′²LC = 3,806:

\[\cos B'=1-\frac{3{,}806}{2}=-0{,}903\Rightarrow B'=154{,}6^\circ,\qquad Z_C'=\frac{48{,}99}{\sqrt{1-3{,}806/4}}=222{,}5\;Ом\]

Формально частота ещё в полосе пропускания (f₂ = 64,97 кГц), но моделировать линию нельзя. Шаг по фазе 154,6° — на длину волны приходится 2,3 звена, а характеристическое сопротивление в 4,5 раза больше волнового сопротивления кабеля (и сильно зависит от частоты). Шаг дискретизации l′ = B′/β′ = 1,38 км при λ′ = 3,22 км.
